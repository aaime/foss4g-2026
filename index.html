Shared GeoServer package

Preconfigured binary used by both workshops. Download and unzip before you start.

Once started, GeoServer runs at http://localhost:8083/geoserver — port 8083, not the usual 8080.

Running it requires Java 17 or newer. If you don't have it, you have two options:

  • Install a JDK 17+ from Adoptium.
  • Or follow DOCKER.md inside the zip to run a Java environment as a container.
